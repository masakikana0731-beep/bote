# 検証用スクリプト（研究用。アプリ本体からは使わない）

リポジトリのルートで `PYTHONUTF8=1 PYTHONPATH=. python research/<ファイル>` として実行する。

| ファイル | 内容 |
|---|---|
| `exp_train.py` | 実験の共通部品（学習・市場との比較・3連単確率のベクトル計算） |
| `wf_models.py` | ウォークフォワード：四半期ごとに、その直前までのデータで学習したモデルで次の四半期を予想（`data/wf/`） |
| `wf_rules.py` | ルール（レースの選び方×上位N点×オッズ帯×期待値）約26万通りを四半期ごとに集計し、過去だけで選んで次で採点 |
| `multi.py` | 多点買い（流し・ボックス・券種の組み合わせ）をモデルの確率だけで選んだ場合 |
| `race_select.py` / `race_select2.py` | レースを選ぶルールの前半・後半での検証（2026-10-16） |

結果のまとめは `docs/model.md`。
