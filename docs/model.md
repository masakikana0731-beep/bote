## 2. 予測モデルに使う要素（特徴量）

すべて「レース前に分かる情報」だけ。過去成績系は **その日より前のデータだけ** で計算する（未来の情報を混ぜない）。

| 分類 | 特徴量 | 内容 | 重要度 |
|---|---|---|---|
| 過去成績 | r_course_win | その選手が**そのコースから**1着になった率（過去365日、少数サンプルは平均に寄せる） | 43.2% |
| 過去成績 | r_course_top3 | 同じく3着以内率 | 22.5% |
| 選手 | nat_win_rel | 全国勝率（レース内平均との差） | 7.3% |
| 枠・進入 | course | 進入コース（展示の進入） | 6.9% |
| 場 | venue_course_win | その場でそのコースが1着になる率（過去365日） | 4.3% |
| 選手 | nat_win | 全国勝率 | 3.9% |
| 直前 | ex_time_diff | 展示タイム（レース内平均との差） | 3.3% |
| 今節 | meet_mean | 今節のここまでの平均着順 | 2.2% |
| 過去成績 | r_st_rel | 平均ST（過去180日）のレース内平均との差 | 1.0% |
| 枠・進入 | waku | 枠番 | 0.6% |
| 過去成績 | r_finish_60 | 直近60日の平均着順 | 0.5% |
| 機材 | motor_2r_rel | モーター2連率（レース内平均との差） | 0.5% |
| 選手 | grade_num | 級別（A1/A2/B1/B2） | 0.5% |
| 選手 | loc_win / loc_2r / nat_2r | 当地勝率・当地2連率・全国2連率 | 各0.3〜0.4% |
| 直前 | ex_time_rank | 展示タイムのレース内順位 | 0.3% |
| 機材 | motor_2r / boat_2r | モーター・ボート2連率 | 0.2〜0.3% |
| 選手 | weight / age | 体重・年齢 | 各0.2% |

| 水面 | wind / wave | 風速・波高 | 各0.1% |
| レース | rno / race_kind | レース番号・種別（優勝戦/予選…） | 各0.1% |

重要度は LightGBM の gain の割合。**「そのコースでのその選手の実績」と「コース」でほぼ7割**を説明している。

## 3. モデルの仕組み

1. **強さスコア**：LightGBM（LambdaRank：着順の並びを学習する手法）で、各艇の「上位に来やすさ」のスコアを出す
2. **1着確率**：6艇のスコアを softmax で確率にする
3. **2着・3着の確率**：1着を除いた艇で同じ計算を繰り返す（Plackett-Luce）。ただし段階ごとに「温度」を変える
   - 学習結果：1着 1.06 / 2着 0.75 / 3着 0.54
   - 2着・3着ほど実力差どおりに決まりにくい、という意味。素のHarville法（温度を変えない）はこれを過大評価する
4. **3連単120通りの確率** ＝ 1着確率 × 2着確率 × 3着確率

学習の期間分け:
- 学習：2023/10/1〜2026/4/30（135,880レース）※最初の3か月は過去成績を溜めるためだけに使用
- 検証：2026/5/1〜7/14（11,187レース）… 木の本数と温度を決める
- テスト：2026/7/15〜10/12（13,588レース）… 一度も使っていない期間で評価

## 4. モデルの精度（テスト期間）

| 指標 | 学習モデル | コース別勝率だけ | 市場（人気） |
|---|---|---|---|
| 1着を当てる率 | **57.1%** | 54.1% | – |
| 実際の3連単の順位（中央値） | 10位 | – | **9位** |
| 実際の3連単が上位10位以内 | 51.1% | – | **54.5%** |
| 3連単の対数尤度（オッズのある3,106R） | -3.89 | -4.21 | **-3.76** |

**市場（オッズ）のほうが少し正確**。オッズには展示航走の気配・記者情報・大口の資金などが織り込まれているため。
モデルが「期待値1以上（お得）」と判断した買い目でも、実際の回収率は65〜71%だった。

## 5. 買い方パラメータ

| パラメータ | 画面 | 内容 |
|---|---|---|
| ギャンブル性 | スライダ | 狙う配当の目安（0=8倍〜100=300倍） |
| 配当の目安の幅 | スライダ（新） | 目安からどれだけ外れたオッズまで買うか |
| 厳選度 | スライダ（変更） | 買い目ごとの期待値（確率×オッズ）の下限 0〜1.5 |
| 堅いレースを見送る | スライダ（新） | 1着確率が高すぎる艇がいるレースを見送る（配当が低く妙味が少ない） |
| 風速で見送る | 数値（新） | 指定風速以上は荒れやすいので見送る |
| 人気を信じる度合い | スライダ | モデル確率とオッズ由来の確率の混ぜ具合 |
| 点数 | 数値 | 1レースの最大点数 |
| 金額の配分 | 選択 | 払戻を揃える／均等／確率に比例 |
| 1レースの上限 | 数値 | 1レースに使う最大額 |
| 予想モデル | 選択（新） | 学習モデル／簡易モデル |

## 6. 最適化の方法と結果

- 3,000通りのパラメータをランダムに生成
- テスト期間を前半（7/15〜8/28）と後半（8/29〜10/12）に分け、**前半と後半の悪いほうの回収率**で順位付け（片方だけ良い設定を除くため）
- さらに日単位のブートストラップ（5,000回）で回収率の90%区間を計算
- 条件：1日3,000円・最大10R

| 設定 | 的中率 | 回収率 | 90%区間 | プラスになる確率 | 上位2回の的中を除くと | 最長連敗 |
|---|---|---|---|---|---|---|
| 当たる楽しさ | 25% | 86% | 74〜99% | 4% | 83% | 27R |
| バランス | 19% | 99% | 75〜125% | 48% | 90% | 19R |
| 一発狙い | 6% | 137% | 82〜200% | 85% | 106% | 44R |
| 超大穴（参考） | 2% | 178% | 57〜330% | 83% | 62% | 151R |
| 人気のみ（参考） | 26% | 79% | 69〜89% | 0% | 77% | 25R |

### 注意（結果の読み方）
- 3,000通りの中から良かったものを選んでいるので、**同じデータでの成績は実力より良く見える**（選択バイアス）。プラスになる確率も楽観的な値
- 「一発狙い」「超大穴」は的中が少なく、数回の大当たりで結果が決まっている
- 90日・1日3場の抜き取り・確定オッズでの検証。実運用は締切数分前のオッズで買うのでずれる
- 期間が変われば結果も変わる。仮想モードで実際に試して確認するのが確実

## 7. 作り直し方

```bash
pip install -r requirements-ml.txt
python -m boatbot.history download --start 20230701 --end 20261012   # 公式一括データ（初回のみ・数時間）
python -m boatbot.history build                                       # data/history.parquet
python -m boatbot.ml train && python -m boatbot.ml evaluate
python -m boatbot.backtest fetch-odds --days 90 --venues-per-day 3    # 戦略検証用オッズ
python -m boatbot.optimize prepare && python -m boatbot.optimize search --n 3000
```
学習済みモデルは `models/` に入っています（リポジトリに同梱）。ただし本番の予想には過去成績の集計が必要なので、自宅PCでも最初に `history download` と `build` を一度実行してください（数時間）。
アプリ起動中は毎朝、前日分の公式データを自動で取り込み、過去成績の集計を更新する（モデルの再学習は手動）。
