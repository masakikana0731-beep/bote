# 方針1「回収率100%を超える買い方を探す」の記録（2026-10-13〜10-20）

結論：**公開データ（番組表・競走成績・直前情報・オッズ）とこのモデルでは、締切前に買って控除率（約25%）を超え続ける買い方は見つからなかった。**
一番良いのは「ほぼ確実な本命の複勝・単勝」で回収率 100〜104%（ほぼ元返し、2年で +370円/1点100円）。
以後は方針2（予想の見せ方を良くして、自分で考えて買う楽しさを増やす）に切り替える。

---

## 1. 考え方（何を確かめたか）

競艇の払戻は「売上 − 控除（約25%）」を当たった人で分ける。全体の平均回収率は約75%。
これを超えるには、**市場（オッズ）よりも正確に当たりやすさを見積もり、市場が過小評価している目だけを買う**必要がある。そのために:

1. 予測モデルを強くする（市場との差を縮める・市場に無い情報を持つ）
2. モデルと市場の差が大きい目（期待値 = 確率 × オッズ > 1）だけ買う
3. レースを選ぶ・オッズ帯で絞る・賭け方を変える
4. それでも駄目なら、極端に絞る（週1回未満）

## 4. 教訓（見かけに騙されたポイント）

### 4-1. 情報漏れ：レース後に分かる値を使っていた
- 競走成績の「進入コース」は実際のレースのもの。スタート展示と違う艇が **約5%（レースの12%）** ある
- これを使うと「市場より割安な3連単」が大量に見つかり、回収率 200〜400% に見えた。展示の進入に直すと消えた
- **対策**：予想に使う値は「締切前に分かるもの」だけ。学習時と本番で特徴量が一致するかを必ず確認する

### 4-2. 確定オッズを先に知っている前提
- 過去のオッズは確定オッズしか取れない。確定オッズで「期待値 > 1」の目を選ぶと、
  「締切直前にオッズが上がった目」を選んでいることになり、回収率が良く見える
- 実際の締切前オッズとの比較（`docs/results/policy1/win_odds_drift.csv`、単勝・5分前→確定の中央値）:

  | 5分前のオッズ | 確定/5分前 |
  |---|---|
  | 1〜2倍 | 1.18 |
  | 2〜5倍 | 1.31 |
  | 5〜10倍 | 1.00 |
  | 10〜20倍 | 0.76 |
  | 20〜50倍 | 0.50 |
  | 50倍以上 | **0.26** |

  大穴ほど締切直前に買われてオッズが下がる。5分前に「割安」に見えた大穴は、確定ではもう割安ではない
- 紙上の売買（締切前オッズで選ぶ）では、単勝・複勝・拡連複は 54〜83%（確定オッズで選ぶと 102〜138% に見えた）
- **対策**：オッズを使うルールは、締切前オッズで検証する（`python -m boatbot.papertrade`）

### 4-3. たくさん試した中から選ぶと良く見える
- 5,000通り・26万通り・80万通りと増やすほど、偶然 200% を超えるルールが増える
- 過去の四半期で選んだ上位ルール（過去 180〜230%）は、次の四半期では平均 80% 前後に戻った
- **対策**：ウォークフォワード（過去だけで選ぶ → 次の期間で採点、を繰り返す）。モデルも各時点までのデータで学習し直す
- 比較用に「市場の確率だけで同じ探し方」もする（モデルの情報が本当に効いているかを見る）

### 4-4. 賭け方では負けは勝ちに変わらない
- 期待値に比例・ケリー基準にしても、負けている買い方の損が大きくなるだけ（`docs/model.md`）

## 5. それでも分かったこと（方針2で使える）

- モデルは市場（オッズ）に無い情報を少し持っている：混ぜると市場単独より正確（+0.005/レース）
- 市場には「大穴ほど割に合わない」偏りがある（500倍以上は実際の的中が見込みの約0.7倍）
- 「モデルがほぼ確実と見る本命」の複勝・単勝は回収率 100% 前後（負けにくい）
- 締切前のオッズは、大穴ほど確定までに大きく下がる

## 6. 再現方法

```bash
python research/wf_models.py prepare                   # 特徴量
python research/wf_models.py fold 20251231 20260331    # 四半期ごとのモデル（research/run_wf.ps1 で全部）

```
