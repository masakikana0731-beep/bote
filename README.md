# 🚤 ボート予想くん（競艇 自動予想＆買い目通知ツール）

「稼ぐ」より「楽しむ」ための個人用ツールです。
自宅PC／ラズパイで動かし、**スマホのブラウザから操作**します。

- 締切の数分前に公式サイト（boatrace.jp）の出走表・直前情報・3連単オッズを取得
- スライダの設定に沿って買い目と金額を決定し、スマホへ**プッシュ通知**
- 購入はテレボートで**自分でタップ**（買い目コピー → テレボートを開く）
- **1日の最大投資額**・1レース上限・最大参加レース数を超える提案は出さない
- 結果を自動で取り込み、「実際の収支」と「推奨を全部買っていた場合の仮想収支」を表示

## 🤖 自動投資モード

設定画面の「自動投資」で切り替えます。

| モード | 動き |
|---|---|
| オフ | 買い目を通知するだけ。購入は自分で |
| 仮想 | お金を使わず、自動で「買ったこと」にして収支を記録。すぐ使える |
| 本番 | テレボートを自動操作して購入。下の準備が必要 |

> ⚠️ **テレボートの約定 第25条**は、振興会所定の画面・アプリ以外の方法での投票を禁止しており、
> 違反と判断されると**予告なく利用停止**になることがあります。本番モードは自己責任で使ってください。

### 安全装置（本番・仮想共通）
購入の直前に毎回、次のすべてを確認し、1つでも外れたら買いません。
- 1レース上限・1日上限・1日の最大参加レース数
- `BOATBOT_HARD_DAILY_CAP`（PC側の環境変数）による最終上限。画面からはこれ以上に設定できません
- 画面に表示された合計金額と予定金額が一致していること
- 締切30秒前を過ぎていないこと
- 同時に2つの購入を実行しない

止まる条件:
- 投票ボタンを押した後にエラー → 「購入不明」として**すぐ自動投資をオフ**にし、緊急通知を送る（二重購入防止）。画面で「買えていた／買えていなかった」を選んで確定します
- 3回連続で購入失敗 → 自動投資をオフにして通知
- 画面上部の「緊急停止」ボタンでいつでもオフにできる

### 本番モードの準備
テレボートの画面構造は作者が確認できていないため、画面操作は**ご自身で一度録画**して埋める必要があります。

```bash
pip install -r requirements-real.txt
python -m playwright install chromium
cp teleboat_flow.example.py teleboat_flow.py
python -m boatbot.teleboat_cli record   # ブラウザで実際に操作 → 出てきたコードを teleboat_flow.py の TODO に貼る
python -m boatbot.teleboat_cli test --jcd 01 --rno 12   # 投票の直前で止まるテスト（お金は使わない）
```

テストが「✅ 投票直前まで正常に動きました」になったら、次の環境変数を設定して起動し、画面でモードを「本番」にします。

| 変数 | 内容 |
|---|---|
| `BOATBOT_ALLOW_REAL=1` | 本番モードの許可（これが無いと本番購入は必ず失敗する） |
| `BOATBOT_HARD_DAILY_CAP` | 最終上限（円）。必ず設定することを推奨 |
| `TELEBOAT_MEMBER_NO` / `TELEBOAT_PIN` / `TELEBOAT_PASSWORD` / `TELEBOAT_VOTE_PASSWORD` | ログイン情報（`teleboat_flow.py` から `creds.〜` で使う） |
| `TELEBOAT_HEADLESS=0` | ブラウザ画面を表示して動かす（動作確認用） |

- 操作のたびに `data/shots/` へスクリーンショットを保存します。
- ログイン情報は環境変数でのみ渡し、ファイルには書かないでください（`teleboat_flow.py` は git の管理対象外です）。
- テレボートの画面が変わると動かなくなります。その場合は録画し直してください。
- ログイン状態の保存先は `data/teleboat_state.json` です。

## 設定スライダ

| スライダ | 左 (0) | 右 (100) | 効き方 |
|---|---|---|---|
| ギャンブル性 | 本命党 | 大穴狙い | 狙う配当の目安。0=約8倍 / 50=約49倍 / 100=約300倍。目安に近いオッズの中から当たりやすい目を選ぶ |
| 厳選度 | どんどん参加 | 自信がある時だけ | 買い目の平均期待値がしきい値（0.4〜1.2）未満なら見送り。0なら見送らない |
| 人気を信じる度合い | 独自予想 | 人気に乗る | 独自の確率とオッズから逆算した確率を混ぜる比率 |
| 気まぐれ度 | きっちり | 気まぐれ | 買い目選びにランダム性を混ぜる |
| 重視：コース／全国勝率／当地勝率／モーター／展示タイム／スタート | 無視 | 重視 | 各艇の強さを計算するときの重み |

そのほか「1レースの点数」「金額の配分（払戻を揃える／均等／当たりやすい目に厚く）」「対象の場」「締切何分前に予想するか」を設定できます。

### 予想の仕組み（ざっくり）
1. 各艇の強さ = コース別の1着率（全国平均の概算値）＋ 選手勝率・モーター・展示タイム・ST を正規化して重み付け
2. 強さ → softmax で1着確率 → Harville法で3連単120通りの確率
3. 人気スライダに応じてオッズ由来の確率と混ぜる
4. ギャンブル性スライダの「狙う配当の目安」から離れたオッズを減点して並べ替え、上位を点数分選ぶ → 予算内で100円単位に配分

## 過去データでのシミュレーション
```bash
python -m boatbot.backtest fetch --days 30          # 初回は数時間（公式サイトへのアクセス間隔を空けるため）
python -m boatbot.backtest run --compare            # 今の設定とプリセットを比較
python -m boatbot.backtest run --set gamble=70      # 設定を変えて試す（取得済みデータで数秒）
```
確定オッズを使うので、締切数分前のオッズで買う実運用とは多少ずれます。

**的中や利益を保証するものではありません。** 控除率（約25%）があるため、長期的にはマイナスになるのが普通です。

### 予算の数え方（安全側）
「未対応」の買い目も“買ったかもしれない”ので予算を使ったものとして数えます。
買わなかったレースは「見送る」をタップすると予算が戻ります。

## セットアップ（自宅PC / Raspberry Pi）

```bash
git clone <このリポジトリ>
cd bote
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
./run.sh
```

同じWi-Fiのスマホから `http://<PCのIPアドレス>:8000` を開き、「ホーム画面に追加」しておくとアプリのように使えます。

### 環境変数（任意）

| 変数 | 内容 |
|---|---|
| `BOATBOT_TOKEN` | 設定すると画面を開くときにトークン入力が必要になる（外から見られる場合は必ず設定） |
| `NTFY_TOPIC` | [ntfy](https://ntfy.sh/) のトピック名。スマホにntfyアプリを入れて同じトピックを購読すると通知が届く。推測されにくい名前にすること |
| `NTFY_SERVER` | ntfyサーバ（既定 `https://ntfy.sh`） |
| `BOATBOT_PUBLIC_URL` | 通知をタップしたときに開くURL（この画面のURL） |
| `TELEBOAT_URL` | 「テレボートを開く」ボタンのURL（既定 `https://spweb.brtb.jp/`。正しいか未確認なので、普段使っているURLに変更推奨） |
| `BOATBOT_DB` | データベースの場所（既定 `data/boatbot.db`） |

### 外出先から使うには
自宅のPCをインターネットに直接公開するのは避け、[Tailscale](https://tailscale.com/) などのVPNでスマホとPCをつなぐのがおすすめです。

### 常時起動（Linux / Raspberry Pi の例）
`boatbot.service.example` を `/etc/systemd/system/boatbot.service` にコピーし、パスやユーザー名を直してから
```bash
sudo systemctl enable --now boatbot
```

## 注意
- 公式サイトに負荷をかけないよう、アクセス間隔を1.5秒以上空けています。間隔は短くしないでください。
- 公式サイトのHTMLが変わると取得に失敗します（画面上部にエラー表示）。`boatbot/scraper.py` を修正してください。
- 中止・返還・欠場などの扱いは簡易的です。
- 舟券の購入は20歳以上から。のめり込みすぎに注意して、余裕資金で楽しんでください。
